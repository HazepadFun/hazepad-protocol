# Hazepad Roadmap

The roadmap is ordered, not dated. A phase opens when the one before it is finished and checked.

## Phase 1: Foundations
- Public site with live Solana readouts: slot, chain value, top pairs
- Fact register with stated, absent and unconfirmed states
- Brand palette and favicon traced from the logo files
- Route simulator and draft builder that run in the browser

## Phase 2: Contract
- State the contract address in the register
- Open the contract slot at the top of the site for copying
- Publish audit notes alongside the address

## Phase 3: Launch flow
- Wallet connection on the site
- Draft routes saved on-chain with a launch
- Fee Gate live for launched tokens

## Phase 4: Rig Desk
- Rented capacity routes
- Hosted machine routes
- Public purchase records

## Phase 5: Payouts
- Payout Ledger published
- Holder snapshots and distribution
- Rebalancing of a route map after launch

## Phase 6: Openness
- Source repository stated in the register
- Community account stated in the register
- Third-party review of the contracts

Each item moves from planned to done only when it can be shown. Nothing here is a commitment to an outcome.
